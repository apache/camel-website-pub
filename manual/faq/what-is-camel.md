# What is Camel?

Apache Camel ™ is a versatile open-source integration framework based on known [Enterprise Integration Patterns](../../components/4.18.x/eips/enterprise-integration-patterns.md).

Camel empowers you to define routing and mediation rules in a variety of domain-specific languages ([DSL](../dsl.md), such as Java, XML, and YAML). This means you get smart completion of routing rules in your IDE.

Apache Camel uses [URIs](../uris.md) to work directly with any kind of transport or messaging model such as [HTTP](../../components/4.18.x/http-component.md), [Kafka](../../components/4.18.x/kafka-component.md), [JMS](../../components/4.18.x/jms-component.md), [Netty](../../components/4.18.x/netty-component.md) or [AWS S3](../../components/4.18.x/aws2-s3-component.md), as well as pluggable [Components](../component.md) and [Data Format](../data-format.md) options. Apache Camel is a small library with minimal [dependencies](../what-are-the-dependencies.md) for easy embedding in any Java application. Apache Camel lets you work with the same [API](../exchange.md) regardless which kind of transport is used — so learn the API once and you can interact with all the [Components](../../components/4.18.x/index.md) provided out-of-box.

Apache Camel provides support for [Bean Binding](../bean-binding.md) and seamless integration with popular frameworks such as [Spring](../spring.md). Camel also has extensive support for [unit testing](../testing.md) your routes.
