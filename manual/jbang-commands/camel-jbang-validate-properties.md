# camel validate properties

Validate Camel configuration in properties files

> **Note**
> This command is provided by the `validate` plugin. Install it with `camel plugin add validate`.

## Usage

```bash
camel validate properties [options]
```

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `--json` | Output in JSON Format: valid, file and errors of each file, as the MCP tool camel\_validate\_source answers |  | boolean |
| `-h,--help` | Display the help and sub-commands |  | boolean |
