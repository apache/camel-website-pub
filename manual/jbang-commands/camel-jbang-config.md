# camel config

Get and set user configuration values

## Usage

```bash
camel config [options]
```

## Subcommands

 
| Subcommand | Description |
| --- | --- |
| [get](camel-jbang-config-get.md) | Display user configuration value |
| [list](camel-jbang-config-list.md) | Displays user configuration |
| [set](camel-jbang-config-set.md) | Set user configuration value |
| [unset](camel-jbang-config-unset.md) | Remove user configuration value |

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `-h,--help` | Display the help and sub-commands |  | boolean |
