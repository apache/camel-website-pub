# camel kubernetes traits

List the traits that configure the Kubernetes manifest, or the options of one trait

> **Note**
> This command is provided by the `kubernetes` plugin. Install it with `camel plugin add kubernetes`.

## Usage

```bash
camel kubernetes traits [options]
```

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `--json` | Output in JSON Format |  | boolean |
| `-h,--help` | Display this help and exit |  | boolean |
