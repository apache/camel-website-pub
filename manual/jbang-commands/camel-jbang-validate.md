# camel validate

Validate Camel source code

> **Note**
> This command is provided by the `validate` plugin. Install it with `camel plugin add validate`.

## Usage

```bash
camel validate [options]
```

## Subcommands

 
| Subcommand | Description |
| --- | --- |
| [normalize](camel-jbang-validate-normalize.md) | Normalize YAML routes to canonical (explicit) form |
| [properties](camel-jbang-validate-properties.md) | Validate Camel configuration in properties files |
| [source](camel-jbang-validate-source.md) | Validate any Camel source file: YAML, properties, Java, XSLT, XML |
| [yaml](camel-jbang-validate-yaml.md) | Parse and validate YAML routes |

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `-h,--help` | Display the help and sub-commands |  | boolean |
