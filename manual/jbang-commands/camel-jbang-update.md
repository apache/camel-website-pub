# camel update

Update Camel project

## Usage

```bash
camel update [options]
```

## Subcommands

 
| Subcommand | Description |
| --- | --- |
| [list](camel-jbang-update-list.md) | List available update versions for Camel and its runtime variants |
| [run](camel-jbang-update-run.md) | Update Camel project |

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `-h,--help` | Display the help and sub-commands |  | boolean |
