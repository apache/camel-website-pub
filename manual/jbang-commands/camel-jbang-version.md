# camel version

Manage Camel versions

## Usage

```bash
camel version [options]
```

## Subcommands

 
| Subcommand | Description |
| --- | --- |
| [get](camel-jbang-version-get.md) | Displays current Camel version |
| [list](camel-jbang-version-list.md) | Displays available Camel versions |
| [set](camel-jbang-version-set.md) | Set/change current Camel version |

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `-h,--help` | Display the help and sub-commands |  | boolean |
