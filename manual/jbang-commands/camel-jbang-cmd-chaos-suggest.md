# camel cmd chaos-suggest

Suggest chaos rules to try in a running integration, per route (camel-chaos, for development only)

## Usage

```bash
camel cmd chaos-suggest [options]
```

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `--timeout` | How long to wait for the integration to answer, in millis or as a duration such as 30s | 10000 | long |
| `-h,--help` | Display this help and exit |  | boolean |
