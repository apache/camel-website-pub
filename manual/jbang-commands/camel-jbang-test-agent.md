# camel test agent

Manage Citrus agents

> **Note**
> This command is provided by the `test` plugin. Install it with `camel plugin add test`.

## Usage

```bash
camel test agent [options]
```

## Subcommands

 
| Subcommand | Description |
| --- | --- |
| [run](camel-jbang-test-agent-run.md) | Runs tests on the agent server |
| [start](camel-jbang-test-agent-start.md) | Starts the Citrus agent as a server |
| [stop](camel-jbang-test-agent-stop.md) | Stop the Citrus agent service |

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `-h,--help` | Display the help and sub-commands |  | boolean |
