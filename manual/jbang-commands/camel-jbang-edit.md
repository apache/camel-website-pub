# camel edit

Edit Camel with suggestions and diagnostics

> **Note**
> This command is provided by the `edit` plugin. Install it with `camel plugin add edit`.

## Usage

```bash
camel edit [options]
```

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `-h,--help` | Display this help and exit |  | boolean |
