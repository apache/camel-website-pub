# camel test

Manage tests for Camel applications

> **Note**
> This command is provided by the `test` plugin. Install it with `camel plugin add test`.

## Usage

```bash
camel test [options]
```

## Subcommands

 
| Subcommand | Description |
| --- | --- |
| [agent](camel-jbang-test-agent.md) | Manage Citrus agents |
| [init](camel-jbang-test-init.md) | Creates a new Citrus test |
| [inspect](camel-jbang-test-inspect.md) | Inspect a Citrus test and its source code in order to provide detailed information such as used endpoints as well as required modules and dependencies. |
| [ps](camel-jbang-test-ps.md) | List running Citrus tests |
| [run](camel-jbang-test-run.md) | Run as local Citrus test |

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `-h,--help` | Display the help and sub-commands |  | boolean |
