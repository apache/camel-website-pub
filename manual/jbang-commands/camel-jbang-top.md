# camel top

Top status of Camel integrations

## Usage

```bash
camel top [options]
```

## Subcommands

 
| Subcommand | Description |
| --- | --- |
| [context](camel-jbang-top-context.md) | Top status of Camel integrations |
| [group](camel-jbang-top-group.md) | Top performing route groups |
| [processor](camel-jbang-top-processor.md) | Top performing processors |
| [route](camel-jbang-top-route.md) | Top performing routes |
| [source](camel-jbang-top-source.md) | List top processors (source) in a running Camel integration |

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `--watch` | Execute periodically and showing output fullscreen |  | boolean |
| `-h,--help` | Display the help and sub-commands |  | boolean |
