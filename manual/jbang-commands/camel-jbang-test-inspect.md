# camel test inspect

Inspect a Citrus test and its source code in order to provide detailed information such as used endpoints as well as required modules and dependencies.

> **Note**
> This command is provided by the `test` plugin. Install it with `camel plugin add test`.

## Usage

```bash
camel test inspect [options]
```

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `-h,--help` | Display the help and sub-commands |  | boolean |
