# camel catalog

List artifacts from Camel Catalog

## Usage

```bash
camel catalog [options]
```

## Subcommands

 
| Subcommand | Description |
| --- | --- |
| [component](camel-jbang-catalog-component.md) | List components from the Camel Catalog |
| [dataformat](camel-jbang-catalog-dataformat.md) | List data formats from the Camel Catalog |
| [dev-console](camel-jbang-catalog-dev-console.md) | List dev-consoles from the Camel Catalog |
| [kamelet](camel-jbang-catalog-kamelet.md) | List Kamelets from the Kamelet Catalog |
| [language](camel-jbang-catalog-language.md) | List expression languages from the Camel Catalog |
| [other](camel-jbang-catalog-other.md) | List miscellaneous components from the Camel Catalog |
| [transformer](camel-jbang-catalog-transformer.md) | List data type transformers from the Camel Catalog |

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `-h,--help` | Display the help and sub-commands |  | boolean |
