# camel route-parser

Parses Java route and dumps route structure

> **Note**
> This command is provided by the `route-parser` plugin. Install it with `camel plugin add route-parser`.

## Usage

```bash
camel route-parser [options]
```

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `--raw` | To output raw without metadata |  | boolean |
| `--watch` | Execute periodically and showing output fullscreen |  | boolean |
| `-h,--help` | Display the help and sub-commands |  | boolean |
