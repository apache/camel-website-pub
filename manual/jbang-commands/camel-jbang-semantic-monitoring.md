# camel semantic monitoring

Read current semantic measurements

## Usage

```bash
camel semantic monitoring [options]
```

## Options

   
| Option | Description | Default | Type |
| --- | --- | --- | --- |
| `--json` | Output a single JSON document |  | boolean |
| `--source` | Producer or configured metric source name |  | String |
| `--timeout` | Timeout waiting for the integration, in millis or as a duration such as 30s | 60000 | long |
| `-h,--help` | Display the help and sub-commands |  | boolean |
