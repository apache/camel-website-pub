# JSON

JSON is a [Data Format](data-format.md) to marshal and unmarshal Java objects to and from [JSON](http://www.json.org/).

For JSON to object marshalling, Camel provides integration with many popular JSON libraries such as:

-   Jackson
    
-   Google GSon
    
-   JSonB
    

How to use JSON with Camel then see the documentation (for the JSON data library of choice) in the list of [Data Formats](../components/4.22.x/dataformats/index.md).
