We are pleased to announce the 3.32.0 release of Apache Camel Quarkus.

Camel Quarkus 3.32.0 aligns with the Camel 4.18.0 and Quarkus 3.32.0 releases.

For more information, please check the Release notes.

Camel 4.18.0

Please refer to the Camel 4.18.0 release announcement and the Camel 4.18 what’s new blog post for more details.

Quarkus 3.32.0

Please refer to the Quarkus 3.32.0 release notes for more details. You can find the full release announcement on the Quarkus Blog.
