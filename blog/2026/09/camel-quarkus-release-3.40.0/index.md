We are pleased to announce the 3.40.0 LTS release of Camel Quarkus.

Camel Quarkus 3.40.0 aligns with the Camel 4.22.1 LTS and Quarkus 3.40.1 LTS releases.

For more information, please check the [Release notes](../../../../releases/q-3.40.0/).

## Camel 4.22.1

Please refer to the [Camel 4.22 what’s new blog post](../../../../blog/2026/08/camel422-whatsnew/index.md) for more details.

## Quarkus 3.40.1

Please refer to the [Quarkus 3.40.0 release notes](https://github.com/quarkusio/quarkus/releases/tag/3.40.0) and [Quarkus 3.40.1 release notes](https://github.com/quarkusio/quarkus/releases/tag/3.40.1) for more details.

## What’s next

Quarkus 3.40 is the last feature release of the Quarkus 3.x stream, and the Quarkus team is now focusing on Quarkus 4.x.

The Camel Quarkus team will soon begin work on adopting Quarkus 4, which will be delivered in the Camel Quarkus 4.x release stream. There is work to be done in both Camel core and Camel Quarkus first. Stay tuned for more details as they become available.
