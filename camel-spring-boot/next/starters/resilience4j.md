# Resilience4j

Spring Boot auto-configuration for Camel Resilience4j Circuit Breaker.

This starter integrates [Resilience4j](https://resilience4j.readme.io) with Camel’s Circuit Breaker EIP, providing fault tolerance patterns (circuit breaker, bulkhead, timeout) for Camel routes.

## Maven coordinates

```xml
<dependency>
    <groupId>org.apache.camel.springboot</groupId>
    <artifactId>camel-resilience4j-starter</artifactId>
</dependency>
```
