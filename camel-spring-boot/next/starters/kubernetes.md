# Kubernetes ConfigMap

Perform operations on Kubernetes ConfigMaps and get notified on ConfigMaps changes.

## Maven coordinates

```xml
<dependency>
    <groupId>org.apache.camel.springboot</groupId>
    <artifactId>camel-kubernetes-starter</artifactId>
</dependency>
```
