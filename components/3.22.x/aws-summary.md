# AWS

The **aws-** component allows you to work with the [AWS](https://aws.amazon.com/). AWS offers a great palette of different components like cloudwatch, DynamoDB streams, storage service, email and queue services. The main reason to use AWS is its cloud computing platform.

## AWS components

See the following for usage of each component:

[AWS Athena](aws2-athena-component.md)

Access AWS Athena service using AWS SDK version 2.x.

[AWS Cloudtrail](aws-cloudtrail-component.md)

Consume events from Amazon Cloudtrail using AWS SDK version 2.x.

[AWS CloudWatch](aws2-cw-component.md)

Sending metrics to AWS CloudWatch using AWS SDK version 2.x.

[AWS DynamoDB](aws2-ddb-component.md)

Store and retrieve data from AWS DynamoDB service using AWS SDK version 2.x.

[AWS DynamoDB Streams](aws2-ddbstream-component.md)

[AWS Elastic Compute Cloud (EC2)](aws2-ec2-component.md)

Manage AWS EC2 instances using AWS SDK version 2.x.

[AWS Elastic Container Service (ECS)](aws2-ecs-component.md)

Manage AWS ECS cluster instances using AWS SDK version 2.x.

[AWS Elastic Kubernetes Service (EKS)](aws2-eks-component.md)

[AWS Eventbridge](aws2-eventbridge-component.md)

[AWS Key Management Service (KMS)](aws2-kms-component.md)
