# Azure

The Camel Components for [Microsoft Azure Services](https://azure.microsoft.com/) provide connectivity to Azure services from Camel.

## Azure components

See the following for usage of each component:

[Azure CosmosDB](azure-cosmosdb-component.md)

To read and write records to the CosmosDB database on Azure cloud platform.

[Azure Event Grid](azure-eventgrid-component.md)

Send events to Azure Event Grid topics.

[Azure Event Hubs](azure-eventhubs-component.md)

Send and receive events to/from Azure Event Hubs using AMQP protocol.

[Azure Files](azure-files-component.md)

Send and receive files to Azure storage file share

[Azure Functions](azure-functions-component.md)

Invoke and manage Azure Functions.

[Azure Key Vault](azure-key-vault-component.md)

Manage secrets and keys in Azure Key Vault Service

[Azure ServiceBus](azure-servicebus-component.md)

Send and receive messages to/from Azure Service Bus.

[Azure Storage Blob Service](azure-storage-blob-component.md)

Store and retrieve blobs from Azure Storage Blob Service.

[Azure Storage Data Lake Service](azure-storage-datalake-component.md)

Sends and receives files to/from Azure Data Lake Storage.

[Azure Storage Queue Service](azure-storage-queue-component.md)

Stores and retrieves messages to/from Azure Storage Queue.
