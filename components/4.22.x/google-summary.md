# Google

The **google-** component allows you to work with the [G Suite](https://gsuite.google.co.in/). Google offers a great palette of different components like use of calender, mail, sheets and drive . The main reason to use Google is the G Suite features.

## Google components

See the following for usage of each component:

[Google BigQuery](google-bigquery-component.md)

Google BigQuery data warehouse for analytics.

[Google BigQuery Standard SQL](google-bigquery-sql-component.md)

Access Google Cloud BigQuery service using SQL queries.

[Google Calendar](google-calendar-component.md)

Perform various operations on a Google Calendar.

[Google Calendar Stream](google-calendar-stream-component.md)

Poll for changes in a Google Calendar.

[Google Cloud Functions](google-functions-component.md)

Manage and invoke Google Cloud Functions

[Google Cloud Speech To Text](google-speech-to-text-component.md)

Transcribe audio to text using Google Cloud Speech-to-Text API

[Google Cloud Text To Speech](google-text-to-speech-component.md)

Synthesize speech from text using the Google Cloud Text-to-Speech API

[Google Cloud Vision](google-vision-component.md)

Detect labels, text, faces, logos and more on images through Google Cloud Vision API

[Google Drive](google-drive-component.md)

Manage files in Google Drive.

[Google Firestore](google-firestore-component.md)

Store and retrieve data from Google Cloud Firestore NoSQL database.

[Google Mail](google-mail-component.md)

Manage messages in Google Mail.

[Google Mail Stream](google-mail-stream-component.md)

Poll for incoming messages in Google Mail.

[Google Pubsub](google-pubsub-component.md)

Send and receive messages to/from Google Cloud Platform PubSub Service.

[Google Secret Manager](google-secret-manager-component.md)

Manage Google Secret Manager Secrets

[Google Sheets](google-sheets-component.md)

Manage spreadsheets in Google Sheets.

[Google Sheets Stream](google-sheets-stream-component.md)

Poll for changes in Google Sheets.

[Google Storage](google-storage-component.md)

Store and retrieve objects from Google Cloud Storage Service using the google-cloud-storage library.

[Google Vertex AI](google-vertexai-component.md)

Interact with Google Cloud Vertex AI generative models.
