# Huawei Cloud

The Camel components for [Huawei Cloud Services](https://www.huaweicloud.com/intl/en-us/) which provides connectivity to Huawei Cloud services from Camel.

## Huawei Cloud components

See the following for usage of each component:

[Huawei Cloud Face Recognition Service (FRS)](hwcloud-frs-component.md)

Face Recognition Service (FRS) is an intelligent service that uses computers to process, analyze, and understand facial images based on human facial features.

[Huawei Cloud Image Recognition](hwcloud-imagerecognition-component.md)

To identify objects, scenes, and concepts in images on Huawei Cloud

[Huawei Distributed Message Service (DMS)](hwcloud-dms-component.md)

To integrate with a fully managed, high-performance message queuing service on Huawei Cloud

[Huawei FunctionGraph](hwcloud-functiongraph-component.md)

To call serverless functions on Huawei Cloud

[Huawei Identity and Access Management (IAM)](hwcloud-iam-component.md)

To securely manage users on Huawei Cloud

[Huawei Object Storage Service (OBS)](hwcloud-obs-component.md)

To provide stable, secure, efficient, and easy-to-use cloud storage service on Huawei Cloud

[Huawei Simple Message Notification (SMN)](hwcloud-smn-component.md)

To broadcast messages and connect cloud services through notifications on Huawei Cloud
