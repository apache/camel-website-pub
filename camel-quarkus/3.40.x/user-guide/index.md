# User guide

This guide is for developers writing Camel applications on top of Quarkus.

[Getting started with Camel](../../../manual/getting-started.md) is user guide to start with Camel in general.

> **Warning**
> Camel Quarkus is a new project and this guide is a work in progress. [Issue reports](https://github.com/apache/camel-quarkus/issues) and fixes are welcome.

## Which Camel components are supported on Quarkus?

The answer is very easy: those that have a Quarkus extension - see the [complete list](../reference/index.md).
