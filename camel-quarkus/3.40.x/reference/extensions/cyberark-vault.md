# CyberArk Vault

JVM since3.31.0 Native since3.31.0

Retrieve secrets from CyberArk Conjur Vault.

## What’s inside

-   [CyberArk Vault component](../../../../components/4.22.x/cyberark-vault-component.md), URI syntax: `cyberark-vault:label`
    

Please refer to the above link for usage and configuration details.

## Maven coordinates

[Create a new project with this extension on code.quarkus.io](https://code.quarkus.io/?extension-search=camel-quarkus-cyberark-vault)

Or add the coordinates to your existing project:

```xml
<dependency>
    <groupId>org.apache.camel.quarkus</groupId>
    <artifactId>camel-quarkus-cyberark-vault</artifactId>
</dependency>
```
