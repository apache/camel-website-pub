# uniVocity CSV

JVM since1.1.0 Native since1.2.0

Marshal and unmarshal Java objects from and to CSV (Comma Separated Values) using UniVocity Parsers.

## What’s inside

-   [uniVocity CSV data format](../../../../components/4.18.x/dataformats/univocityCsv-dataformat.md)
    
-   [uniVocity Fixed Length data format](../../../../components/4.18.x/dataformats/univocityFixed-dataformat.md)
    
-   [uniVocity TSV data format](../../../../components/4.18.x/dataformats/univocityTsv-dataformat.md)
    

Please refer to the above links for usage and configuration details.

## Maven coordinates

[Create a new project with this extension on code.quarkus.io](https://code.quarkus.io/?extension-search=camel-quarkus-univocity-parsers)

Or add the coordinates to your existing project:

```xml
<dependency>
    <groupId>org.apache.camel.quarkus</groupId>
    <artifactId>camel-quarkus-univocity-parsers</artifactId>
</dependency>
```

Check the [User guide](../../user-guide/index.md) for more information about writing Camel Quarkus applications.
