# Apache Camel extensions for Quarkus

> **Note**
> This version (3.33.x) of Camel Quarkus depends on:
>
> -   [Camel](../../components/4.18.x/index.md) at version 4.18.4
>     
> -   [Quarkus](https://quarkus.io) at version 3.33.3.2
>     
>
> This release will not be updated, but rather replaced by a new release.

This project aims to bring the awesome integration capabilities of [Apache Camel](../../manual/index.md) and its vast [component library](../../components/4.18.x/index.md) to the [Quarkus runtime](https://quarkus.io/).

This enables users to take advantage of the performance benefits, [developer joy](https://quarkus.io/developer-joy) and the [container first ethos](https://quarkus.io/container-first) that Quarkus provides.

Camel Quarkus provides [Quarkus extensions](reference/index.md) for many of the Camel components. You can [define Camel routes](user-guide/defining-camel-routes.md) using the Java DSL, XML, YAML and other languages.
