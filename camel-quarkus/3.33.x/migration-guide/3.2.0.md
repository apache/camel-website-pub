# Camel Quarkus 3.2.0 Migration Guide

The following guide outlines how to adapt your code to changes that were made in Camel Quarkus 3.2.0.

## Changes in Quarkus

Please refer to [Quarkus 3.0.0 Migration Guide](https://github.com/quarkusio/quarkus/wiki/Migration-Guide-3.0).

## Changes in Camel

Please refer to [Apache Camel 3.x to 4.0 Migration guide](../../../manual/camel-4-migration-guide.md).
