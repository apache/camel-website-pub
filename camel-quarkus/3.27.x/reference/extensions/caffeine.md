# Caffeine Cache

JVM since1.1.0 Native since1.2.0

Perform caching operations using Caffeine Cache.

## What’s inside

-   [Caffeine Cache component](../../../../components/4.14.x/caffeine-cache-component.md), URI syntax: `caffeine-cache:cacheName`
    
-   [Caffeine LoadCache component](../../../../components/4.14.x/caffeine-loadcache-component.md), URI syntax: `caffeine-loadcache:cacheName`
    

Please refer to the above links for usage and configuration details.

## Maven coordinates

[Create a new project with this extension on code.quarkus.io](https://code.quarkus.io/?extension-search=camel-quarkus-caffeine)

Or add the coordinates to your existing project:

```xml
<dependency>
    <groupId>org.apache.camel.quarkus</groupId>
    <artifactId>camel-quarkus-caffeine</artifactId>
</dependency>
```

Check the [User guide](../../user-guide/index.md) for more information about writing Camel Quarkus applications.
