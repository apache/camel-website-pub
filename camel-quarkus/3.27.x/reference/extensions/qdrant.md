# Qdrant

JVM since3.10.0 Native since3.10.0

Perform operations on the Qdrant Vector Database.

## What’s inside

-   [Qdrant component](../../../../components/4.14.x/qdrant-component.md), URI syntax: `qdrant:collection`
    

Please refer to the above link for usage and configuration details.

## Maven coordinates

[Create a new project with this extension on code.quarkus.io](https://code.quarkus.io/?extension-search=camel-quarkus-qdrant)

Or add the coordinates to your existing project:

```xml
<dependency>
    <groupId>org.apache.camel.quarkus</groupId>
    <artifactId>camel-quarkus-qdrant</artifactId>
</dependency>
```

Check the [User guide](../../user-guide/index.md) for more information about writing Camel Quarkus applications.
