# Stitch

JVM since1.8.0 Nativeunsupported

Stitch is a cloud ETL service that integrates various data sources into a central data warehouse through various integrations.

## What’s inside

-   [Stitch component](../../../../components/4.22.x/stitch-component.md), URI syntax: `stitch:tableName`
    

Please refer to the above link for usage and configuration details.

## Maven coordinates

```xml
<dependency>
    <groupId>org.apache.camel.quarkus</groupId>
    <artifactId>camel-quarkus-stitch</artifactId>
</dependency>
```

Check the [User guide](../../user-guide/index.md) for more information about writing Camel Quarkus applications.
