# Azure CosmosDB

JVM since2.0.0 Nativeunsupported

To read and write records to the CosmosDB database on Azure cloud platform.

## What’s inside

-   [Azure CosmosDB component](../../../../components/next/azure-cosmosdb-component.md), URI syntax: `azure-cosmosdb:databaseName/containerName`
    

Please refer to the above link for usage and configuration details.

## Maven coordinates

```xml
<dependency>
    <groupId>org.apache.camel.quarkus</groupId>
    <artifactId>camel-quarkus-azure-cosmosdb</artifactId>
</dependency>
```

Check the [User guide](../../user-guide/index.md) for more information about writing Camel Quarkus applications.
