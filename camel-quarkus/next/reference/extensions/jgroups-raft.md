# JGroups raft

JVM since1.1.0 Nativeunsupported

Exchange messages with JGroups-raft clusters.

## What’s inside

-   [JGroups raft component](../../../../components/next/jgroups-raft-component.md), URI syntax: `jgroups-raft:clusterName`

