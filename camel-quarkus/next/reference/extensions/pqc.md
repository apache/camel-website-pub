[Create a new project with this extension on code.quarkus.io](https://code.quarkus.io/?extension-search=camel-quarkus-pqc)

Or add the coordinates to your existing project:

```xml
<dependency>

    <artifactId>camel-quarkus-pqc</artifactId>
</dependency>
```
