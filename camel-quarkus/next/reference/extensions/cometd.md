# CometD

JVM since1.1.0 Nativeunsupported

Offers publish/subscribe, peer-to-peer (via a server), and RPC style messaging using the CometD/Bayeux protocol.

## What’s inside

-   [CometD component](../../../../components/next/cometd-component.md), URI syntax: `cometd:host:port/channelName`
    
-   [CometD (Secure) component](../../../../components/next/cometd-component.md), URI syntax: `cometds:host:port/channelName`
    

Please refer to the above links for usage and configuration details.

## Maven coordinates

```xml
<dependency>
    <groupId>org.apache.camel.quarkus</groupId>
    <artifactId>camel-quarkus-cometd</artifactId>
</dependency>
```
