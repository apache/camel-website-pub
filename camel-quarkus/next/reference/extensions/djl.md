# Deep Java Library

JVM since1.1.0 Nativeunsupported

Infer Deep Learning models from message exchanges data using Deep Java Library (DJL).

## What’s inside

-   [Deep Java Library component](../../../../components/4.22.x/djl-component.md), URI syntax: `djl:application`
    

Please refer to the above link for usage and configuration details.

```xml
<dependency>
    <groupId>org.apache.camel.quarkus</groupId>
    <artifactId>camel-quarkus-djl</artifactId>
</dependency>
```

Check the [User guide](../../user-guide/index.md) for more information about writing Camel Quarkus applications.
