# PostgresSQL Replication Slot

JVM since1.1.0 Native since1.2.0

Poll for PostgreSQL Write-Ahead Log (WAL) records using Streaming Replication Slots.

## What’s inside

-   [PostgreSQL Replication Slot component](../../../../components/next/pg-replication-slot-component.md), URI syntax: `pg-replication-slot:host:port/database/slot:outputPlugin`
    

Please refer to the above link for usage and configuration details.

## Maven coordinates

[Create a new project with this extension on code.quarkus.io](https://code.quarkus.io/?extension-search=camel-quarkus-pg-replication-slot)

Or add the coordinates to your existing project:

```xml
<dependency>
    <groupId>org.apache.camel.quarkus</groupId>
    <artifactId>camel-quarkus-pg-replication-slot</artifactId>
</dependency>
```
