# Exec

JVM since0.4.0 Native since0.4.0

Execute commands on the underlying operating system.

## What’s inside

-   [Exec component](../../../../components/4.18.x/exec-component.md), URI syntax: `exec:executable`
    

Please refer to the above link for usage and configuration details.

## Maven coordinates

[Create a new project with this extension on code.quarkus.io](https://code.quarkus.io/?extension-search=camel-quarkus-exec)

Or add the coordinates to your existing project:

```xml
<dependency>
    <groupId>org.apache.camel.quarkus</groupId>
    <artifactId>camel-quarkus-exec</artifactId>
</dependency>
```

Check the [User guide](../../user-guide/index.md) for more information about writing Camel Quarkus applications.
