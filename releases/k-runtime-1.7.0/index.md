Release is tagged with `camel-k-runtime-parent-1.7.0` in the Git, to fetch it use:

git clone https://git-wip-us.apache.org/repos/asf/camel-k-runtime.git
cd camel-k-runtime
git checkout camel-k-runtime-parent-1.7.0
